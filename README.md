# 🌫️ AQI Dashboard

An interactive web dashboard that displays real-time Air Quality Index (AQI) data across various locations. This project helps users monitor air pollution levels and understand the health implications of current air quality.

## 📸 Preview

![AQI Dashboard Screenshot](./screenshots/dashboard.png) <!-- Replace with actual path -->

## 🚀 Features

- 🌍 View AQI data by city or location
- 📈 Dynamic charts for PM2.5, PM10, O₃, NO₂, SO₂, CO
- ⚠️ Color-coded AQI indicators based on US EPA standards
- 📱 Responsive design for mobile and desktop
- 🕒 Real-time updates using APIs

## 🛠️ Tech Stack

- **Frontend:** React.js / Vue.js / HTML + CSS + JS (Edit as per your stack)
- **Backend:** Node.js / Spring Boot / Flask (Optional)
- **API:** [OpenAQ API](https://docs.openaq.org/) / [Breezometer](https://docs.breezometer.com/)
- **Charting:** Chart.js / Recharts / D3.js
